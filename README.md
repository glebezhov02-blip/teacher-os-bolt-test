# Teacher OS

Build a production-ready web application called "Teacher OS".

This is NOT a CRM.

This is an AI Operating System for a private language teacher.

Style:

- Apple-level minimalism

- Linear.app quality

- Clean spacing

- Large rounded cards

- Premium UI

- Dark sidebar

- Light content area

- Extremely fast feeling

- No gradients except subtle accents

- Beautiful typography

- Responsive

Tech stack:

- React

- TypeScript

- Tailwind

- shadcn/ui

- Supabase

Connect to Supabase later.

The first screen is called Mission Control.

Layout:

Left sidebar.

Main content.

Right AI sidebar.

Mission Control must contain:

Top:

Title

Mission Control

Subtitle:

Everything important for today's teaching.

Top statistics cards:

Students Today

Lessons Today

Homework Waiting

Payments

AI Tasks

Main section:

Today's Lessons

Each lesson is a large card.

Each card shows:

Student

Time

Homework Status

Current Unit

Key Takeaways

AI Advice

Payment Status

Start Lesson button

Cards never automatically resize.

Each section inside the card has its own expand button.

Right sidebar:

AI Inbox

Waiting for Approval

System Health

Quick Actions

Use fake demo data.

Do NOT implement authentication yet.

Do NOT implement backend yet.

Focus only on a beautiful frontend.
